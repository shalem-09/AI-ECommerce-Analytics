# Power BI setup

These are supporting source files for building the report in Power BI Desktop; the binary `.pbix` is intentionally not generated by this Python project.

1. Create the tables with `database\schema.sql` if they do not already exist.
2. Select the intended database explicitly when applying the view definitions (they do not switch databases):
   `Get-Content .\powerbi\sql_views.sql | mysql -u root -p ecommerce_analytics`
3. Install the MySQL connector supported by your Power BI Desktop installation and connect to that same database.
4. For a single flattened fact table, create a blank Power Query and paste `power_query_m_code.txt` into Advanced Editor. Alternatively import the source tables and configure one-to-many relationships from customers, products, and orders to order items.
5. Create the `Calendar` calculated table from the top of `dax_measures.dax` and relate `Calendar[Date]` to `v_sales_detail[order_day]`.
6. Add the remaining measures from `dax_measures.dax`, then follow `dashboard_design.md`.

`v_sales_detail` includes all order statuses; measures explicitly scope revenue and profit to completed orders. `v_monthly_sales` is a compact monthly aggregate. `v_customer_rfm` provides customer-level recency, frequency, and monetary inputs.

The SQL view scripts do not drop tables or alter order/customer/product records. They use `CREATE OR REPLACE VIEW` and apply to the database selected by the MySQL connection. Set the server/database in Power Query to match your local MySQL settings; do not place credentials in the M code.
